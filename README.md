## About Me

Full-stack developer from Pakistan building web products that balance clean UI, practical backend architecture, and real-world functionality. I work mainly with the JavaScript and TypeScript ecosystem and enjoy turning product ideas into scalable applications.

- Focused on `Next.js`, `React`, `Node.js`, `Express`, and `TypeScript`
- Comfortable with `PostgreSQL`, `MongoDB`, `MySQL`, `Prisma`, and `Firebase`
- Interested in `system design`, `software quality`, and `product-driven engineering`
- Currently building a `Hospital Management System` with chatbot integration
- Actively improving backend architecture, deployment workflows, and testing practices
